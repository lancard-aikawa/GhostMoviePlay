## 芯にあるもの

発展形を考えるときの起点。このツールの価値は mp4 ではなく、次の 3 つにある。

1. **AI の仕事は「操作」ではなく「演目の設計」。** ソースを読んで *狙って失敗できる*
   ことが価値であって、UI を自動操作すること自体には価値がない
2. **`plan.json` という人が直せる中間表現**で AI と収録を切り離した
3. **リプレイが決定論的**なので撮り直しが無料

**3 つとも動画に固有ではない。** 発展の余地は全部そこにある。

## A. 媒体を差し替える

`plan.json` は動画専用フォーマットではない。`render` の隣にもう一つレンダラを置く話。

| 出力 | 中身 |
| --- | --- |
| 手順書 (md) | 各ビート = スクショ + 字幕。**動画と手順書が食い違いようがない** |
| README 用 GIF / APNG | 音声なし・字幕だけの短縮版 |
| スライド | シーン = 章、ビート = ページ |
| アプリ内ツアー | coach mark 形式。`actions` の selector をそのまま使える |
| 多言語同時出し | `say` だけ差し替えて 1 収録から複数言語。設計上すでに可能で、束ねる口が無いだけ |

**対話型**が一番面白い。決定論なので「ビート k の直前状態」を再現できるから、
動画の途中で「ここから自分でやってみる」と実アプリに受け渡せる。
失敗例を見せた直後に操作を渡す、という教材になる。

## B. 目的を差し替える —— 撮る道具から、検査する道具へ

`gmp record` は要するに**ナレーション付きの Playwright スクリプト**なので、
落ちたということは UI が変わったということ。

- **ドキュメント腐敗検知。** CI で全 `plan.json` を `record` だけ回す
  （render 不要・AI 不要）。selector が消えたら赤。*説明が古くなったら自動で分かる*
  仕組みになり、動画のほうが副産物になる
- **ビート単位のビジュアル回帰。** ビートに id があるので、差分の指し先を
  「どの説明が壊れたか」で出せる
- **リリース差分動画。** 2 つの tag で同じ plan を撮って並べる、または変わった
  ビートだけ撮り直す

## C. 対象を差し替える

`record` を挿げ替えれば `plan` / `voice` / `render` はそのまま使える。

- **[Android アプリ](android.md)** —— 見積り済み。Pass2 だけの差し替えで届く
- CLI / TUI（pty リプレイ）
- API シーケンス（リクエストとレスポンスを画面に見立てる）
- canvas / WebGL、Jupyter、複数アプリを跨ぐ業務フロー

## D. 「狙って失敗する」だけを取り出す

動画を作らなくても単体で価値がある部分。Pass1 の出力先を変えるだけ。

- **落とし穴監査。** ソースを読んで「ユーザーが踏む典型的な悪手」を列挙・ランク付け
  するレポート。GlossPop の「短い語を登録すると本文がリンクだらけになる」がまさにこれで、
  *動画にする前の段階に既に価値がある*。悪習カタログを題材にする撮り方は
  [統治と習慣を撮る](../governance.md)（**こちらは既存機能だけで回るので ideas ではない**）
- **演習問題ジェネレータ。** 悪手を仕込んだ状態を配って直させる
- **QA のテストケース生成。** 正常系ではなく誤操作パスを吐かせる
- **逆変換。** 人の実操作を録って `plan.json` に起こし、AI に「何が悪かったか」を
  後付けさせる。サポート issue → 再現＋解説動画。AI が UI を読み切れないとき
  （canvas、ログイン必須、業務アプリ）の入口としても効く

## 見立て

1. **B のドキュメント腐敗検知。** 新規実装がほぼ要らないのに、既存の `plan.json` 資産の
   意味が「動画の素」から「生きた仕様」に変わる
2. **A の第二レンダラ（手順書 md）。** `plan.json` が媒体中立な中間表現だと実証できる。
   AI コストは 0 のまま成果物が倍
3. **D の逆変換。** 「AI に撮らせる」の反対側が埋まって、対象アプリ側の制約を迂回できる

[Android](android.md) は単体では 1〜3 より重いが、**オーバーレイを render 時に移す**
という副産物が Web 側にも効くので、そこだけ先に切り出す価値がある。
